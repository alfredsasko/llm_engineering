Welcome to wk4_excercise's documentation!
=========================================

The ``Python code optimizer to C++`` package provides an extensible, modular toolkit for
converting Python code into high-performance C++ using a mix of open- and
closed-source LLM providers. This site collects API documentation and
hands-on guides for using and extending the project.
